URL Shortener
A web application for creating shortened URLs from long links. This project includes a frontend built with HTML, CSS, and JavaScript, and a backend powered by Node.js with Express and MongoDB.

Features
URL Shortening: Generate short URLs for long links.
Persistent Storage: Stores original and shortened URLs in a database.
Redirection: Redirects short URLs to their original links.
Deployed Frontend: Hosted on Netlify for easy access.
Deployed Backend: Hosted on Render for reliable API services.
Technologies Used
Frontend
HTML, CSS, JavaScript: Classic web technologies for the UI.
Backend
Node.js: JavaScript runtime for server-side functionality.
Express.js: Minimal web framework for handling API routes.
MongoDB: Database for storing URLs.
Installation
Prerequisites
Node.js installed on your system.
MongoDB instance or a database connection.
